# سِجِلّ — نظام إدارة الحصص

Node.js + Express + SQLite + JavaScript عادي (RTL عربي).

## التشغيل
```
npm install
npm start     # http://localhost:3000
```
يعمل مع Node 22 LTS.

## الحسابات والمدارس (تعدد المدارس)
- **المدير العام** (`superadmin`): يضيف المدارس ويوقفها ويغيّر كلمة سر مدير أي مدرسة. لا يملك واجهة تعديل بيانات إلا بعد الضغط على «إدارة» لمدرسة معيّنة.
- **مدير المدرسة**: يدير مدرسته فقط، ولا يرى ولا يصل لأي بيانات مدرسة أخرى (كل استعلام مقيّد بـ `school_id`).
- **المعلم**: يرى جدوله فقط. يُنشئ مدير المدرسة حسابه من صفحة «الكادر التدريسي».
- أول تشغيل: يُنشأ المدير العام ومدير «المدرسة الافتراضية» (بياناتك الحالية) — ضع `SUPER_ADMIN_PASSWORD` و`ADMIN_PASSWORD` قبل التشغيل، وإلا تُولَّد وتُطبع مرة واحدة في السجل.
- على Fly.io: `fly secrets set SUPER_ADMIN_PASSWORD=... ADMIN_PASSWORD=...`
- كلمات المرور مشفّرة (scrypt)، والجلسات برمز عشوائي مجزّأ، وقفل 5 دقائق بعد 5 محاولات فاشلة.
- روابط المشاركة/الطباعة العامة تعمل برمز المدرسة (`share_code`) وتُرجع بيانات تلك المدرسة فقط.
- إيقاف مدرسة أو تعليق اشتراكها يمنع الدخول فوراً دون حذف أي بيانات (حقول الاشتراك بنية فقط — لا فوترة).

## سير العمل
1. **الصفوف والشعب**: اختر المرحلة وعدد الشعب (تتولد أ، ب، ج... بترتيب أبجد).
2. **المواد** + **الكادر التدريسي** (المعلم يدرّس أكثر من مادة ومرحلة).
3. **توزيع المواد**: لكل صف (أو كل شعب المرحلة) حدّد **عدد حصص المادة الأسبوعي**، وخيار **السماح بتكرار المادة بنفس اليوم** مع حد أقصى يومي (متتالية قدر الإمكان)، ثم اربط المعلم بالصف والمادة (أو «إسناد تلقائي»).
4. **إعدادات الدوام**: صباحي (الأحد–الثلاثاء 08:00) ومسائي (الأربعاء–الخميس 13:00)، 6 حصص، 40 دقيقة، استراحة 5 دقائق — الأوقات تُحسب تلقائياً.
5. **الجدول الدراسي**: توليد ذكي → تقرير التحقق → تعديل يدوي (سحب وإفلات/تبديل، بلا شرط تخصص) → اعتماد (يقفل التعديل) → طباعة A4 أفقي.

## الاختبارات
- `npm test`: محرك الجدولة.
- `node --no-warnings tests/integration.test.js`: عزل المدارس والمصادقة والأدوار والجدولة (يستخدم شيماً لـ node:sqlite).
- `node --no-warnings tests/legacy-migration.test.js <مجلد-مشروع-قديم> <اسم>`: ترحيل قاعدة بيانات قديمة.

الترحيلات إضافية فقط: لا DROP ولا حذف بيانات. جدولا `subjects` و`school_classes` القديمان يُحفظان باسم `*_pre_mt` كنسخة احتياطية.

ملاحظة النقل لاحقاً إلى PostgreSQL: كل الاستعلامات SQL عادي ومقيّدة بـ `school_id`، والاعتماد على SQLite محصور في `src/db.js` و`src/migrations`.

## v5 — تحكم أدق بالجدول
- **عدد الدروس لكل يوم**: من «إعدادات الدوام» → «عدد الدروس لكل يوم» (لكل الصفوف أو لصف واحد). الأولوية: صف+يوم ← يوم ← إعداد الصف ← عدد دروس الدوام.
- **دروس مثبتة**: من صفحة الجدول → «دروس مثبتة» (صف/كل الصفوف + يوم + الدرس الأخير أو رقم + مادة + معلم أو أي معلم مرتبط). تُحترم عند كل توليد. ويمكن تثبيت أي حصة 📌 من نافذة تعديلها.
- **إعادة التوليد**: يجرّب 8 توزيعات ويطبّق الأفضل المختلف عن الحالي، ويعرض بدائل قابلة للتطبيق (seed) واقتراحات لحل النواقص.
- **التعارض اليدوي**: رسالة واضحة + حلول بضغطة (خانة فارغة، تبديل، معلم بديل، استبدال).
- اختبارات: `node tests/scheduling-v5.test.js`
