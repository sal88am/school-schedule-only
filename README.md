# سِجِلّ — نظام إدارة الحصص الدراسية

نظام ويب لإدارة الكادر التدريسي والصفوف، مع **توليد تلقائي للجدول الأسبوعي**
بدون ما تحتاج تعيّن كل حصة يدوياً.

## المزايا

- **توليد الصفوف تلقائياً**: اختر المرحلة (الأول - السادس) وحدد عدد الشعب —
  تتولد الأسماء تلقائياً بالحروف الأبجدية (الأول أ، الأول ب، الأول ج...).
- **توقيت الحصص مرن**: تحدد توقيت افتراضي لكل رقم حصة يطبّق على كل الأيام،
  وإذا احتجت يوم معيّن يختلف توقيته (مثلاً الخميس دوام مختصر)، تقدر تعدّل توقيت
  ذاك اليوم بس بدون ما يأثر على باقي الأيام.
- **توليد الجدول تلقائياً بضغطة زر**: النظام يوزع المعلمين على كل الصفوف والحصص
  حسب المواد اللي يدرّسها كل معلم، بدون تعارض (نفس المعلم ما يتكرر بنفس الوقت بصفين، ونفس الصف
  ما ياخذ مادتين بنفس الوقت).
- **معلم يدرّس أكثر من مادة**: كل معلم تقدر تحدد له أكثر من مادة (وبالتالي يدخل تلقائياً
  بجداول أكثر من مرحلة دراسية) — التوليد التلقائي يوزعه حسب كل مادة يدرّسها.
- **تعديل يدوي حر بعد التوليد**: تقدر تعدّل أي حصة بالجدول يدوياً وتحط أي معلم بأي مادة،
  بدون أي شرط إنه لازم يدرّس مادته الأساسية فقط.
- **جدول قابل للتعديل**: بعد التوليد التلقائي تقدر تضيف/تحذف أي حصة يدوياً.
- **قابل للمشاركة والطباعة**: رابط مباشر (بدون تسجيل دخول) لعرض جدول صف معيّن
  أو معلم معيّن أو الجدول الكامل، مع زر طباعة مباشر.
- إعداد أيام الدوام الأسبوعية (افتراضياً الأحد-الخميس، قابلة للتغيير).
- قاعدة بيانات محلية (SQLite) — ما تحتاج إنترنت للتشغيل.

## المتطلبات

- Node.js نسخة 18 أو أحدث (يُفضّل 20 أو 22 LTS لتفادي مشاكل التثبيت).

## خطوات التشغيل

```bash
npm install
cp .env.example .env
```

عدّل بملف `.env`:
- `ADMIN_PASSWORD`: كلمة مرور لوحة التحكم.
- `PORT`: المنفذ، افتراضياً 3000.

```bash
npm start
```

افتح `http://localhost:3000` وسجّل دخول.

## ترتيب الاستخدام المقترح

1. **المواد الدراسية**: أضف كل المواد (الرياضيات، اللغة العربية...).
2. **الكادر التدريسي**: أضف كل معلم واختر تخصصه من قائمة المواد
   (لازم يطابق اسم المادة بالضبط عشان يشتغل التوليد التلقائي).
3. **الصفوف والشعب**: ولّد كل مرحلة بعدد الشعب وعدد الحصص باليوم.
4. **توقيت الحصص**: حدد وقت بداية/نهاية كل رقم حصة (اختر "كل أيام الدوام" للتوقيت
   العام، أو يوم محدد فقط إذا هذا اليوم يختلف عن الباقي).
5. **الإعدادات**: تأكد أيام الدوام صحيحة.
6. **الجدول الدراسي**: اضغط "توليد الجدول تلقائياً" — وعدّل يدوياً إذا احتجت.
7. من نفس صفحة الجدول، اختر "صف معيّن" أو "معلم معيّن" واضغط **مشاركة** أو **طباعة**.

## ملاحظة عن التوليد التلقائي

الخوارزمية توزّع كل معلم حسب المواد اللي حددتها له على كل الصفوف، وتتجنب:
- تكرار نفس المعلم بنفس اليوم والحصة بصفين مختلفين.
- تكرار نفس المادة حصتين متتاليتين لنفس الصف (إذا فيه مواد بديلة).

إذا ظهرت لك حصص "فارغة" بعد التوليد، السبب الغالب إنه عدد المعلمين لمادة معينة
غير كافٍ لتغطية كل الصفوف بنفس الوقت — أضف معلمين أكثر لتلك المادة أو عدّل
الحصص الفارغة يدوياً من نفس الصفحة.

## هيكل المشروع

```
school-schedule-only/
├── src/
│   ├── server.js
│   ├── db.js
│   └── routes/
│       ├── teachers.js
│       ├── lookups.js        # المواد (عام)
│       ├── classes.js        # توليد الصفوف والشعب
│       ├── periodTimes.js    # توقيت الحصص
│       ├── settings.js       # أيام الدوام
│       ├── schedule.js       # الجدول + التوليد التلقائي
│       └── publicSchedule.js # مسارات المشاركة/الطباعة (بدون تسجيل دخول)
├── public/
│   ├── index.html            # لوحة التحكم
│   ├── print.html            # صفحة المشاركة والطباعة (عامة)
│   ├── styles.css
│   └── app.js
├── data/                     # قاعدة بيانات SQLite (تنشأ تلقائياً)
└── .env.example
```

## ملاحظات

- رابط `/print.html` عام بدون كلمة مرور — أي شخص عنده الرابط يقدر يشوف الجدول
  (قراءة فقط، ما يقدر يعدّل). هذا يخليه سهل للمشاركة مع المعلمين أو الطلاب.
- لبيئة إنتاج حقيقية بعدة مستخدمين إداريين، يُنصح بإضافة نظام مستخدمين وجلسات حقيقي.
